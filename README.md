# Mohit Portfolio

A responsive personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Lucide React, and React Icons.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Replace Images

- Hero portrait: replace `public/images/hero-placeholder.webp`.
- Project thumbnails: replace `public/images/project-finvisa.webp`, `public/images/project-nova.webp`, and `public/images/project-zenbank.webp`.
- Keep the same file names to avoid code changes, or update paths in `data/portfolio.ts`.

## Edit Content

- Navigation, experience, skills, projects, and social links live in `data/portfolio.ts`.
- Main section layouts live in `components/portfolio`.
- Page metadata lives in `app/layout.tsx`.

## Build

```bash
npm run build
```
